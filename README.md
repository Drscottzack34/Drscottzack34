# Scott Zack, Michigan

Investor and entrepreneur in Bloomfield Hills, Michigan. Owner of [Creek Equity](https://creekequity.com), a private investment company formed in 2017 that founds, funds, and acquires founder-led and family-owned businesses with its own capital and holds them for the long term.

Former forward for the Ohio State Buckeyes (number 34, 1994-95).
